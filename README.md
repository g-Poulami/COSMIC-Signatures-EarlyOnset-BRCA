# COSMIC-Signatures-EarlyOnset-BRCA

## Description
This repository contains the workflow for comparing mutational signatures between early-onset and late-onset breast cancer using TCGA data.

## Contents
- `signature_analysis.R`: Main R script for data download, matrix generation, and signature refitting.
- `Analysis_Documentation.pdf`: Detailed technical documentation of the methodology and statistical approach.

## Requirements
- R version 4.0+
- Bioconductor packages: TCGAbiolinks, maftools, MutationalPatterns
- Reference Genome: BSgenome.Hsapiens.UCSC.hg38
